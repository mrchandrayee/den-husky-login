A beautiful dog-themed login page featuring a husky illustration with eye-following and password-peek animations. Pure HTML/CSS/JS.

---

## ✨ Features

- 🐺 Husky illustration with eye-following cursor
- 🙈 Password field peek/hide animation
- 🎨 Beautiful dark themed UI
- 📱 Fully responsive
- ⚡ Zero dependencies
